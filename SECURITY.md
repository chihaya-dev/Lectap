# Security reporting / セキュリティ上の報告

## English

Please do not report suspected vulnerabilities in public issues or comments.

Use GitHub's [private vulnerability reporting](https://github.com/chihaya-dev/Lectap/security/advisories/new) to contact the maintainer privately. A GitHub account is required.

Include the Lectap version, Windows version, reproduction steps, and the potential impact. Remove personal information, local paths, user names, credentials, and private files from any supporting material.

Reports are reviewed as time permits. A response or fix date is not guaranteed.

---

## 日本語

脆弱性の可能性がある内容は、公開Issueやコメントには投稿しないでください。

GitHubの[非公開の脆弱性報告](https://github.com/chihaya-dev/Lectap/security/advisories/new)から、開発者へ非公開でご連絡ください。GitHubアカウントが必要です。

Lectapのバージョン、Windowsのバージョン、再現手順、想定される影響を添えてください。資料から個人情報、ローカルパス、ユーザー名、認証情報、非公開ファイルを除いてください。

可能な範囲で確認します。返信や修正の時期はお約束できません。
